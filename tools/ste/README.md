# STE checks

Run `python tools/ste/lint.py` from the repository root.
The tool checks deterministic project rules that can operate without the ASD controlled dictionary.

The tool checks classification metadata, sentence limits, contractions, terminology data, and exemption data.
The tool does not prove complete ASD-STE100 compliance.
Use semantic STE review for meaning, approved dictionary use, parts of speech, and sentence construction.
