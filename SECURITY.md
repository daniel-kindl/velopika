# Security policy

Do not report a suspected vulnerability in a public issue.
Use GitHub private vulnerability reporting for this repository.
Open the Security tab, then select the private reporting action.

Include the affected revision, platform, reproduction steps, and expected security effect when possible.
Do not include credentials, tokens, or unrelated personal data.

Velopika preserves Chromium sandboxing, site isolation, certificate handling, renderer protection, and exploit mitigation.
A change to these boundaries needs an explicit security review and owner approval.
